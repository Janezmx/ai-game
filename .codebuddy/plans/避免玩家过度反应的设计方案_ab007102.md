## 需求概述

「清醒边界」是一款"识破心理操控"主题的对话游戏（5 关：煤气灯效应 / 职场PUA / 亲情绑架 / 匿名网络攻击 / 隐性歧视）。玩家通关后存在明确的教育副作用：习得"识别操控"的框架却缺少"什么时候不该套用这个框架"的对照经验，于是把正常的批评、情绪化表达、关心、边界清晰的要求，都读成 PUA 或煤气灯——即**假阳性（过度反应）**。

用户需要一份完整设计方案，回答"如何避免玩家玩完之后过度反应别人的话"。

## 核心诉求（已澄清确认）

- **本次只产出设计方案与话术清单，不落任何代码**；给出候选改动清单供用户勾选后再决定实施范围。
- 覆盖四个环节：课前导读卡、对话对战过程（明辨铃话术与实时反馈）、复盘报告、成长/结算页。
- 允许在现有四维评分（边界意识/情绪稳定/认知清晰/坚定回应）之外**新增"辨别力/校准"指标**，用于区分"真实的善意批评"与"操控"，并让过度攻击型回应降分。

## 方案总体思路（三层防护，文档须按此组织）

1. **教育层**：把"识别信号"与"不算操控的对照反例"成对呈现——只教信号会让人见谁都像操控者，补上反例才能形成辨别力。
2. **过程层**：明辨铃话术池固定纳入"温和确认型"策略（求证意图 / 陈述感受 / 就事论事 / 拒绝接盘），保证每轮至少 1 条低对抗选项；对"贴标签、指责动机、绝对化、拒绝沟通"的回应给出**轻量、不打断流程**的实时提示。
3. **结果层**：新增校准反馈 + 复盘"可能误判的情形"与"若对方是善意"的替代回应 + 成长/结算长期强化"边界不是对所有人设防"。

## 关键技术结论（文档内需给出的技术判断）

### 1. 校准指标的三种落位方式（须给出推荐与取舍）

- **A. 扩展 `DimensionScores` 为第 5 维 `calibration`**：语义最完整，但牵动面最大——`shared` 类型、`utils/dimensions.ts`（`DIMENSION_KEYS`/`emptyDimensions`/`normalizeDimensions`/`averageOf`/`averageDimensions`/`hasAnyScore`）、`gameStore` 派生与持久化、`ReviewScreen` 评分条与雷达、`reportExport`、后端 `DIMENSION_KEYS`/`toPercentScore`/`isPlaceholderDimensions`/结算公式、`SavedReviewReport`。会改变既有综合分口径，历史成绩与榜单被稀释。
- **B. 在 `NPCResponseAssessment` 上新增独立字段（如 `calibration` + `misjudged?: boolean`）**：侵入小，四维均分与历史口径完全不变；代价是需自建聚合与存档兼容，复盘/成长页单独展示该反馈。
- **C. 不改结构，只调评估提示词口径**：在 `ASSESSMENT_INSTRUCTION_TEMPLATE` 中明确"读心/贴标签/人身攻击式回应不得给高 `assertiveResponse`，需封顶"，并在 `INSIGHT_PROMPT` 中补充"先确认型"策略。
- **推荐：B 为主 + C 兜底**（低侵入、不改历史口径，同时立刻在提示词层抑制攻击性最大化）。

### 2. 善意干扰轮机制设计要点

- 每关固定/随机插入 1 轮"真诚但刺耳的反馈"（非操控），制造假阳性判断机会；**UI 上不得提前打标签泄题**，该轮性质只在复盘揭晓。
- 判定与联动：玩家贴标签/指责动机/拒绝沟通 → 校准分下降、护盾无增益并给出"这可能是一次误判"提示；玩家先确认/就事论事 → 校准分上升。
- 必须说明其与 `turnCount`/`MAX_TURNS`、结算公式、`degraded` 兜底路径的衔接方式，且确认不新增串行 LLM 请求（沿用每轮 1 次评估调用）。

### 3. 兼容与回归

- 旧存档（`version=1`，无校准字段）缺失时一律"不展示、不计分"；`avgScore` 与 `bestScores` 保持四维口径不变。
- 明辨铃新话术须通过 `cleanAlternativeText` 的既有约束（第一人称、无引导词、无动作描写、10-40 字）。

### 4. 风险与反向风险控制

- 过度校正风险：若把"示弱/忍让"设为唯一正确解，会从"怀疑一切"滑向"必须委曲求全"。设计中"先确认"只作为**并列选项**之一，复盘须同时给出"这确实是操控时"的处理方式。
- 结论定性风险：把"NPC 动机定性"改为"这句话的作用 + 我的可选回应"，降低"别人都在操控我"的世界观强化。
