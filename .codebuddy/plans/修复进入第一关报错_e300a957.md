## 用户需求

进入第一关（心域备战界面 `HeartDomainPrepareScreen`）点击「开始对话入侵」时报错 `Uncaught ReferenceError: storeSetAmuletText is not defined`，导致无法进入对话战斗阶段。用户已明确决定**下架护身符功能**，要求仅删除导致报错的残留调用，保留其他空状态、无副作用。

## 核心修复内容

- 移除 `HeartDomainPrepareScreen` 中指向已删除护身符 store action 的残留调用 `storeSetAmuletText(amuletText)`。
- 修正 `handleStartBattle` 的 `useCallback` 依赖数组，移除其中未定义的 `storeSetAmuletText` 与 `amuletText`，避免引用错误。
- 修复后进入第一关不再报错，可正常进入对话战斗阶段（`GamePhase.DialogueBattle`）。

## 技术栈

- 前端框架：React + react-native-web（通过 Vite 在 Web 端运行）
- 状态管理：Zustand（`useGameStore`）
- 预览/调试：`npm run dev`（前端 3000，后端 3001）

## 实现方案

本修复属于「清理半删除功能的残留引用」的局部逻辑修正，不涉及新增架构或 UI。

根因：最近的重构删除了护身符功能的 UI 输入、组件本地 `amuletText` state 以及 store 的 `setAmuletText` action，但漏删了 `HeartDomainPrepareScreen.tsx` 中 `handleStartBattle` 里的 `storeSetAmuletText(amuletText)` 调用及其 `useCallback` 依赖项，导致运行时 `ReferenceError`。

修复策略：仅删除这处悬空调用并修正依赖数组，使组件恢复到「不含护身符功能」的干净状态。

### 关键修改点（`frontend/src/components/HeartDomainPrepareScreen.tsx`）

- 第 195-199 行 `handleStartBattle`：
- 删除 `storeSetAmuletText(amuletText);` 这一行；
- 依赖数组由 `[setPhase, onComplete, storeSetAmuletText, amuletText]` 改为 `[setPhase, onComplete]`。

## 实现注意事项

- **保持最小改动面**：按用户选择，仅删报错调用，不做功能扩展。
- **保留空状态无副作用**：`gameStore.ts` 中 `amuletText: ""` 状态保留（恒为空）；`BattleScreen.tsx` 第 711 行读取 `store.amuletText` 的护身符横幅因值为空字符串，`{store.amuletText ? ... : null}` 不会再渲染，无需改动即实现「功能下架」，无运行时错误。
- **不清理孤儿样式**：该组件中 `amuletSection`/`amuletInput` 等样式在此前重构中已变为孤儿样式，属无害死代码，本次不额外改动以控制改动范围。
- **验证**：修改后运行 `npm run typecheck`（即 `npm run typecheck --workspace=@aigame/shared` 及前端类型检查），并实际进入第一关点击「开始对话入侵」确认不再报错。
