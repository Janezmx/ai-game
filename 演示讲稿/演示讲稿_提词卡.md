# 演示提词卡 ｜ 清醒边界

**开场前 60 秒**：联网 ✓　预热过第 2 关 ✓　桌面放好已导出的报告 ✓
**节奏锚点**（不用记，扫一眼对表）
- 20 分钟版：`1'首页 → 2'导读 → 3'30"对战 → 9'修复 → 10'复盘 → 14'设计决策 → 17'30"收尾`
- 10 分钟版：`40"开场 → 1'10"导读 → 1'50"对战 → 5'修复 → 5'40"复盘 → 8'40"收尾`

> 用法：每步只做三件事——**点 → 说第一句 → 抛出关键词**，说完就停，别自己加细节。
> `★` = 必讲重点　`[10]` = 10 分钟版可跳过

---

## 分镜提词

**▸1　首页**
- 点：不动
- 说：这是五关路线，也是五种高频场景。
- 词：定位「守护你的心域，识别并抵御无形操控」· 已掌握 N/5 · **最后一行「辨别，不是怀疑」**

**▸2　选关**
- 点：「⚔️ 开始修行」→ 选**第 2 关「职场打压」**
- 说：我选职场关，大家最容易代入。

**▸3　课前导读**　`★` `[10 用 40 秒，四块各一句]`
- 点：停在「📚 课前导读」卡，**先别开始**
- 说：只教识别，会教出**见谁都像操控者**的人。
- 词：🔍 识别信号 → ⚠️ **这些不算操控**（逐条反例）→ ⏸ **先确认，再反击**（先要具体 → 再说感受 → 后定边界）→ 💬 健康应对 + 📝 真实案例
- 收：**有信号、有反例，才叫辨别力。**

**▸4　对战·第 1 轮（故意被带偏）**
- 点：发一句情绪化回击（如"你少在这阴阳怪气"）
- 说：听着解气，但你看结算——**控制力没掉，抵抗值反而掉了**。
- 词：**攻击对方 ≠ 守住自己**

**▸5　对战·第 2 轮（明辨铃）**
- 点：「明辨铃」→ 采纳一条 → 发送
- 说：AI 教练在你答不上来时递话，但给的是**三条不同风格的路**，你自己挑。
- 词：法器有冷却（简单无冷却 / 困难 3 回合）

**▸6　对战·第 3 轮（法器）**　`[10]`
- 点：用一次法器
- 说：心盾加抵抗值，真言镜、破谎矛削对方控制力。

**▸7　讲"分数怎么来的"**　`★ 20 分钟版必讲`
- 说：四个维度——边界意识、情绪稳定、认知清晰、坚定回应。
- 词：**边界 + 情绪 → 抵抗值损耗**（情绪一慌掉得更快）· **坚定 + 认知 → 削对方控制力** · 主维 0.6 + 辅维 0.4 · 单轮钳位 ±15 · **连续 2 轮有效且控制力 < 30 才认输**；打满 5 回合看是否 < 50

**▸8　胜负横幅**
- 点：赢/输横幅
- 说：**赢了这一局，不等于现实里对方就是错的。**
- 词：失败那句——别急着把对方都当成操控者，先看清楚再回应

**▸9　修复页**
- 点：**画一圈边界**（覆盖率 ≥ 80% 才算修好）→ 跟着呼吸
- 说：先重绘边界、再呼吸，不是点一下跳过。
- 词：护盾 **胜 −5 / 败 −25 / 修复最多 +20** → **只有输了才会让心域变薄**

**▸10　复盘·逐轮**
- 点：往下滚
- 说：每轮四件事——他说了什么 / 你怎么回 / **这句话的作用** / 四维评分。
- 词：只讲「这句话的作用」，**不给对方人格下定论**

**▸11　复盘·把练习带回现实**　`★ 慢讲`
- 点：滚到「🌱 把练习带回现实」
- 说：这里按关卡定制，三块内容。
- 词：① 本关现实对照 → ② **本关最容易被误读成操控的**（含判据）→ ③ **三个自检问题**
- 三问：**是模式还是一次？针对事还是针对人？你表态后他给标准吗？**
- 金句：**都是能观察到的行为，不需要猜对方的心思——而猜心思正是过度怀疑的起点。**

**▸12　导出报告**
- 点：「导出文本」→ 打开桌面已存好的 Markdown
- 说：可存档、可发学员、可做培训留痕。
- 词：**教育产品必须能留下痕迹，否则没法评估**

**▸13　成长页**　`[10 一句带过]`
- 点：「📊 成长记录」
- 说：四维雷达（可切三口径）/ 8 个徽章 / 对战记录可点开历史报告。
- 词：雷达图下那句——**坚定回应不是越硬越好**

**▸14　三个设计决策**　`[10 并进问答，不单独讲]`
- 说①：这类内容最大的副作用是**让人变得过度戒备**，我们做了四层对冲。
- 词①：课前反例 · 「先确认」选项 · 复盘误判对照 · 离场三问；**同时不奖励道歉讨好**（防另一个极端）
- 说②：**教学产品不能编数据。**
- 词②：三级模型降级 → 短内容重试 → 解析抢修 → **降级前重试** → **兜底标"不计成绩"**
- 说③：三个口径锁住，历史成绩可比。
- 词③：四维口径固定 · 兜底轮不计成绩 · 改名不动存档

**▸15　收尾：要三样东西**
- 说：一个**决定**（是否试点）、一个**资源**（心理顾问 + 20–30 名学员）、一个 **2 周窗口**。
- 词：两周后交付 **前后测数据 + 学员访谈 + 迭代清单**（**不用"学员觉得有用"当证据**）
- 金句：**边界不是对所有人都设防，它只是让你更清楚——谁可以走近一点。**

## 应急（出现即照读）

| 现象 | 照读 |
| --- | --- |
| 开场白等 5–15 秒 | NPC 台词是实时生成的；网络异常时有本地兜底台词，不会卡住 |
| 红色错误条 +「重试」 | 这是我们**主动报错而不是假装成功**；点重试会**原样重发刚才那一轮** |
| 弹框「未获取到有效数据」 | 系统判断评分不可信，就**标为不计成绩**并继续，复盘也会标明——**不拿假分数当成绩** |

## 红线（一句都别说）

1. 不说"能治病/能治愈"——是**心理韧性训练工具**。
2. 不承诺效果。
3. 不用"学员觉得有用"当效果证据。
4. 未完成项（明辨铃「先确认」策略、校准指标、真话轮）**主动说已排期**。
